To start a local development server,
execute npm run dev from the frontend directory.
Once the server starts, open your web browser and go to [http://localhost:5173/](http://localhost:5173/) to view the site.


To launch the Django development server, 
run the command "python manage.py runserver" in the project directory. 
Once the server starts, open your web browser and go to http://127.0.0.1:8000/ to view the site.
For now its only local.
